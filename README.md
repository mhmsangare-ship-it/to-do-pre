# Сервис To-Do

Одностраничное приложение списка дел, проектная работа Яндекс Практикума.

## Функциональность

- при загрузке страницы выводится список задач;
- добавление новой задачи через форму (задача появляется в начале списка);
- удаление задачи;
- копирование задачи (копия появляется в начале списка);
- редактирование текста задачи (contenteditable);
- все изменения сохраняются в localStorage и не пропадают после перезагрузки страницы.

## Технологии

- HTML5, CSS3 (БЭМ)
- JavaScript (DOM, template, события, localStorage, JSON)

## Запуск

Открыть файл `index.html` в браузере.
